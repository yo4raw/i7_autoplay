## 実フレームコーパス（git に入っていない）

`tests/corpus_raw/`（14状態・507枚・69MB）は実機なしで `detect()` の回帰を検証できる資産だが、
サイズが大きいので `.gitignore` で除外している。clone した環境には存在しない。

採取するには周回中に次を並走させる。入力を一切送らないので周回を妨げない。

```bash
python -u tools/ops/corpus_collector.py 1800    # 30分ぶん採取
```

`tests/test_corpus_smoke.py` はコーパスが無ければ skip されるので、
`.venv/bin/python -m unittest discover -s tests` はコーパス無しでも通る。

## 1. 概要

### 1.1 目的
アイドリッシュセブン（以下 IDOLiSH7）の「累計イベント」における、ライブ（リズムゲーム）の
AUTO 周回作業を、macOS の **iPhone ミラーリング** 経由で自動化する Python プログラムの
仕様を定義する。単調な周回操作を無人で繰り返し、累計ポイントを蓄積することを目的とする。

### 1.2 背景
累計イベントは、規定のライブを AUTO で何度も繰り返してポイントを稼ぐ作業ゲー要素が強い。
手動周回は拘束時間が長く負担が大きいため、画面認識ベースの自動化により省力化する。

### 1.3 用語定義
| 用語 | 定義 |
|------|------|
| 周回 | ライブを1回プレイして報酬を受け取る一連の流れ |
| 累計pt | イベントで蓄積される累計ポイント |
| AUTO | ゲーム内の自動演奏モード |
| iPhone ミラーリング | macOS Sequoia 以降の、iPhone 画面を Mac に表示・操作する機能 |
| テンプレートマッチング | 参照画像を画面内から探索して一致箇所を特定する画像認識手法 |
| FSM | 有限状態機械（Finite State Machine）。本ツールの制御モデル |
| TCC | macOS のプライバシー権限管理（Transparency, Consent, and Control） |
| ROI | 関心領域（Region of Interest）。認識・OCR を限定する画面範囲 |

### 1.4 対象読者・位置づけ
本書は本ツールの開発者・利用者を対象とする。実装フェーズの設計土台であり、ゲーム UI の
更新に応じて改訂される前提のドラフトである。

## 3. スコープ

### 3.1 対象範囲
- ① ライブ/バトルの周回（開始 → AUTO 進行 → クリア → 報酬受け取り → 繰り返し）
- ② スタミナ回復（不足検知 → ドリンク/回復アイテム使用 → 在庫管理）
- ③ ポップアップ処理（レベルアップ・ログインボーナス・お知らせ・通信エラー等の自動クローズ）
- ④ 停止条件判定（目標周回数到達・アイテム枯渇・連続エラー・手動キルスイッチ）
- ⑤ 進捗トラッキング（周回数カウント、累計pt/スタミナ残量の OCR 取得・記録）

### 3.2 非対象範囲
- ガチャ・課金操作（一切行わない）
- ストーリー進行・初回設定・チュートリアル
- 編成（ユニット）の自動最適化（現状の編成のまま「決定」のみ）
- 複数アカウントの切替・同時運用

### 3.3 制約事項
- ゲーム UI の更新時はテンプレ画像の差し替え／再取得が必要（破綻し得る）。
- 実行中は iPhone ミラーリングが最前面を占有する（[architecture.md](architecture.md)「4. システム構成・アーキテクチャ」・`specification.md`「16. 既知のリスク・制約」）。

## 13. セキュリティ・規約上の注意
- **ゲーム利用規約**: 多くのゲームは自動化・BOT・マクロ等を禁止しており、本ツールの利用は
  **規約違反となる可能性が高い**。違反時はアカウント停止・データ削除等の措置を受け得る。
- **自己責任**: 本ツールの利用は完全に自己責任で行うこと。開発者は一切の責任を負わない。
- **権限の取扱い**: 画面録画・アクセシビリティは強力な権限。信頼できる環境でのみ付与し、
  不要になったら無効化すること。本ツールは画面・入力を外部送信しない（ローカル完結）。
- **入力の占有**: 実行中はミラーリングが最前面を占有し合成クリックを送る。意図しない操作を
  避けるため、実行前に他の重要操作を完了し、キルスイッチ（ウィンドウを閉じる／ホットキー）を把握しておくこと。
