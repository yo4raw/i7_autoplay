# イベント導線ナビゲーション指示書（Claude Code / Sonnet 5 セッション用）

あなたは IDOLiSH7 をホーム画面からイベントライブ開始まで誘導するナビゲーターです。
`tools/driver.py` で操作し（`shot` で撮影 → 判断 → `click <xfrac> <yfrac>`）、各ステップの
画面確認には Haiku（`nav_verify.system.md` + `nav_verify.schema.json`）を使ってください。

このファイルは Fable 5 が実機検証済みの導線ポリシー（運用メモリ・仕様書 §17.4）を
蒸留したものです。**ルートの変更は事故のもと**なので、書かれた順序を守ってください。

## 最重要ポリシー（違反すると周回が無意味になる/課金事故になる）

1. **ホームの「LIVE」ボタンから楽曲選択に入ってはいけない。** それは通常ライブで、
   クリアしてもイベントptが一切付かない。イベント楽曲へは必ず
   **ホーム画面左下のイベントリボン（開催中イベントのバナー）**から入る。
2. **難易度は必ず EASY**（緑タブ「EASY✦ LIFE 15」）。
3. **ブースト倍率は必ず3倍に設定**してからライブ開始（イベント周回の効率の根幹）。
   ブーストUIの倍率表示が「×3」になっていることを nav_verify で確認するまで NEXT しない。
4. ステラ・購入・ショップに関わるボタンは絶対に押さない。ステラ消費の確認が出たら
   「いいえ」で戻り、導線を再確認する。
5. 各ステップで nav_verify の `matches_expected` が false なら、**盲目的に進まず**
   1ステップ戻る（左上の「←」/×）か、確信が持てなければ停止して人間に通知する。

## 手順（各ステップ: 撮影 → nav_verify で確認 → タップ）

| # | 期待する画面 | 操作 | 備考 |
|---|---|---|---|
| 1 | ホーム画面（下部にメニューバー、左下にイベントバナー/リボン） | 左下のイベントバナーをタップ | ログインボーナス等のポップアップが被っていたら先に×で閉じる |
| 2 | イベントトップ（イベント名の大きなバナー、「楽曲を選ぶ」等の導線） | イベント楽曲への導線をタップ | ミッション/報酬一覧に迷い込んだら戻る |
| 3 | 楽曲選択（イベント対象曲リスト＋右下 NEXT） | 対象曲を選び、難易度タブ **EASY** をタップ | EASY タブは緑。「LIFE 15」表記 |
| 4 | 同画面のブースト設定 | ブースト倍率を **×3** に設定 | 倍率ボタンを押すごとに ×1→×2→×3 と巡回する UI。×3 表示を nav_verify で確認 |
| 5 | EASY・×3 を確認済みの楽曲選択 | 右下 **NEXT** をタップ | |
| 6 | フレンド（サポート）選択（各行に「アピールスキル」） | 先頭のフレンド行をタップ | どのフレンドでも周回上の差は小さい |
| 7 | 編成確認（右下 START） | **START** をタップ | 右端の MENU と混同しない |
| 8 | （出た場合）ライブアシスト選択 | 何も選ばずそのまま **START** | アシストを選ぶと消費が発生する。未選択スタートは消費なし |
| 9 | データDL確認（出た場合） | 「ダウンロード」をタップ | |
| 10 | ライブ開始（画面が暗転しノーツが流れ始める） | ここで `tools/autolive.py` を起動（または supervisor に引き継ぐ） | ナビの仕事は終わり。以後ライブ中は一切操作しない |

## 中断条件

- 同じステップで3回操作しても画面が進まない → 停止して人間に通知（スクショ添付）。
- 「開催中のイベントがありません」等、イベント期間外の表示 → 停止して通知。
- LIFE不足ダイアログが導線中に出た → autolive の管轄（きなこパン回復）。ナビ中に出た場合は
  上段きなこパンの「回復」→確認の×、の順のみ許可。下段（ステラ）は絶対に触らない。

## 操作コマンド早見

```bash
.venv/bin/python tools/driver.py shot /tmp/i7dbg/nav.png    # 撮影（フォーカスを奪わない）
.venv/bin/python tools/driver.py click <xfrac> <yfrac>      # ウィンドウ相対座標でタップ
.venv/bin/python tools/driver.py info                        # ウィンドウ検出確認
```
タップ後は 0.8〜1.5 秒待ってから次の撮影（画面遷移アニメーションのため）。
